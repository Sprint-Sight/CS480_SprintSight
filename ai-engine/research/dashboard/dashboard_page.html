SprintSight grading trials

Five local Ollama models graded two real CS203 sprints and five synthetic fixtures, three repeats each, on six rubric dimensions. Pilot with small n: no significance claims, and every figure shows its n.

2. Per-model scorecard

No composite score. Accuracy uses only dimensions present in every run of that model and script (the coverage badge says which). The baseline always predicts 5.5 on the same cells. Ordering counts expected-order links that pass the noise-aware check; "gold-consistent" drops the link the team-authored gold itself breaks.

Cross-model agreement

Pearson r on matched bundle x dimension means across both scripts. Not shown below 5 points. Points where both models scored 1 inflate r, so r is also shown without them.

3. Signed error against the reference

Mean over repeats of model score minus reference score. Blue means harsher than the reference, orange more generous. Each cell shows the error and its n of valid repeats. Overall uses complete runs only.

4. Fixture trajectories and expected order

Fixtures are placed in the expected order for the chosen dimension, best first. Dots are means over three repeats, with bars of one standard deviation. Hollow diamonds are the team-authored gold. Chips show each link of the expected order: pass, fail, or no data.

5. Reliability and latency

Seconds per run

Each dot is one run. The tall tick is the median and the short tick is p95. Ringed dots took more than 3x the model's median (retry spiral).

Latency and stability table

Stability is the standard deviation across the 3 repeats per bundle x dimension, averaged. Temperature is 0, so near-zero spread reflects deterministic decoding, not validity.

6. Grounding

Judge coverage is runs with citation metrics over runs. The code check asks whether each cited identifier appears in the prompt the model was sent (from audit logs). "Dropped by code" is the pipeline's own resolver. Contributor-summary citations are lines such as "Student3: 20 commits, +170/-201 lines" that the prompt shows but the resolver cannot match.
